// features

Compress and extract .7z in Finder

After install, right-click a file or folder → Services (on some older macOS versions: Quick Actions). Four actions ship by default.

~/Library/Services/

Compress with 7-Zip

Create a .7z archive next to the selection — the Finder equivalent of Windows “Add to archive” with 7-Zip.

extract · here

Uncompress with 7-Zip Here

Extract archive contents into the same folder as the .7z (full paths). Ideal when you want files right where the archive lives.

extract · named folder

Uncompress with 7-Zip to Folder

Permanent extract into a folder named after the archive (e.g. Photos.7z → Photos/).

$TMPDIR/7zip-mac

Open with 7-Zip

Browse without clutter: clears a temp workspace, extracts contents there, opens Finder. Reused on every Open so old extracts do not pile up.

// how it works

How to install 7-Zip for Mac in three steps

Paste the install command

Run the one-liner in Terminal. It finds or installs 7zz via Homebrew and writes Automator Service bundles to ~/Library/Services.

Right-click in Finder

Select files or a .7z archive → Services → pick Compress, Uncompress Here, Uncompress to Folder, or Open with 7-Zip.

Work with .7z natively

High-ratio 7z compression and extract on macOS without buying a ZIP utility. Powered by the same 7-Zip engine Windows users know — CLI packaged as Finder Services.

// faq

FAQ — open 7z on Mac & more

Common questions about installing 7-Zip on macOS, extracting 7z files, and Finder menus.

How do I install 7-Zip for Mac?

Open Terminal and run curl -fsSL https://chengsokdara.github.io/7z | bash. The script installs 7zz if needed and registers the Finder Services.

How do I open a 7z file on Mac?

Right-click the archive → Services → Open with 7-Zip to browse in a temp folder, or use Uncompress with 7-Zip Here / to Folder for a permanent extract.

Where is the menu item in Finder?

Look under Services on recent macOS versions. If it is missing, relaunch Finder or enable the actions under System Settings → Keyboard → Keyboard Shortcuts → Services.

Uncompress Here vs to Folder?

Here extracts into the archive’s directory. to Folder creates a permanent folder named after the archive, then extracts into it.

Is there a full 7-Zip GUI for Mac?

Homebrew ships the CLI. 7zip-mac does not bundle a Windows-style GUI; Open with 7-Zip is a lightweight temp extract + Finder view. Apps like Keka or BetterZip offer richer browsers if you need them.

Do I need Homebrew?

Only if 7zz is not already installed. The installer runs brew install sevenzip when the binary is missing.

How do I uninstall?

curl -fsSL https://chengsokdara.github.io/7z | bash -s -- --uninstall

Is 7-Zip for Mac free?

Yes — MIT licensed. Optional support via GitHub Sponsors is appreciated but never required.
